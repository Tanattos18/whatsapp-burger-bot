# Skill: Integração Pix

Lê `pix.js` para entender as diferentes modalidades de pagamento Pix: estático (copia e cola), Mercado Pago e Asaas.

## Como usar

Quando o usuário precisar configurar ou modificar pagamentos Pix, use esta skill para:
1. Ler `pix.js` para entender os modos disponíveis
2. Identificar qual modo está configurado no .env (PIX_MODO)
3. Entender como gerar QR Code e payload
4. Modificar configurações de pagamento
