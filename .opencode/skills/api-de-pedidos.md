# Skill: API de Pedidos

Entende os endpoints da API REST para gerenciamento de pedidos.

## Como usar

Para integrar ou modificar a API:
1. GET /api/pedidos - lista pedidos
2. GET /api/stats - estatísticas
3. PUT /api/pedidos/:id/status - atualiza status
4. Entender formato de resposta
