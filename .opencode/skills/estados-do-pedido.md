# Skill: Estados do Pedido

Entende os status lifecycle de um pedido: novo → confirmado → em_preparo → saiu_entrega → entregue.

## Como usar

Quando houver dúvidas sobre status de pedidos, use esta skill para:
1. Listar todos os status posibles
2. Entendertransições permitidas
3. Verificar notificações por status
4. Modificar fluxo de status
5. Debugar problemas
