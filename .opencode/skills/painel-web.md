# Skill: Painel Web

Lê `painel.js` para entender o servidor web que exibe pedidos em tempo real, estatísticas e gestão de status.

## Como usar

Quando o usuário precisar modificar ou melhorar o painel de pedidos, use esta skill para:
1. Ler `painel.js` para entender as rotas da API
2. Identificar endpoints: `/`, `/api/pedidos`, `/api/stats`, `/api/pedidos/:id/status`
3. Entender a integração com WhatsApp para notificações
4. Modificar o HTML do painel ou adicionar novas funcionalidades
