# Skill: Debug de Problemas

Lê `ANALISE_PROBLEMAS.md` e `CHECKLIST.md` para identificar issues conhecidos e suas soluções. Ajuda a resolver problemas recorrentes mais rápido.

## Como usar

Quando o usuário_reportar problemas ou erros, use esta skill para:
1. Ler `ANALISE_PROBLEMAS.md` para ver problemas identificados
2. Ler `CHECKLIST.md` para verificar items de debug
3. Verificar se o problema já é conhecido
4. Aplicar a solução documentada ou investigar
