# Skill: Análise de DB

Lê `storage.js`, `orders.js` e o schema do SQLite para entender como pedidos são salvos e consultados. Útil para criar relatórios ou debugar dados.

## Como usar

Quando o usuário precisar entender ou modificar como os dados são armazenados, use esta skill para:
1. Ler `storage.js` para entender a inicialização do DB
2. Ler `orders.js` para ver as funções de CRUD
3. Consultar o arquivo `.db` se necessário para ver a estrutura real
4. Identificar queries para relatórios ou debug
