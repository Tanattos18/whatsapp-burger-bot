# Skill: Fluxo de Conversa

Lê o fluxo de conversation states para entender como o cliente navega pelo menu.

## Como usar

Para entender ou modificar o fluxo de conversas, use esta skill para:
1. Mapear os estados do fluxo
2. Identificar triggeres e ações
3. Adicionar нов etapas
4. Modificar validações
5. Debugar estados
