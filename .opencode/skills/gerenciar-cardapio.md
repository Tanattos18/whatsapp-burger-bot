# Skill: Gerenciar Cardápio

Lê `cardapio.js` para adicionar, remover ou modificar produtos do cardápio.

## Como usar

Quando o usuário precisar alterar o cardápio, use esta skill para:
1. Ler `cardapio.js` para ver produtos atuais
2. Adicionar novo produto (seguir formato existente)
3. Modificar preço ou descrição
4. Remover produto (cuidado com IDs)
5. Entender formatação das mensagens
