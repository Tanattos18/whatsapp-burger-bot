# Skill: Notificações Telegram

Lê `telegram.js` para entender como enviar notificações automáticas para a cozinha quando houver novos pedidos.

## Como usar

Quando o usuário precisar configurar ou modificar notificações Telegram, use esta skill para:
1. Ler `telegram.js` para entender a API
2. Identificar como obter token e chat_id
3. Entender os tipos de notificação (novo pedido, status atualizado)
4. Configurar ou modificar mensagens
