# Skill: Fluxo de Pedidos

Lê `flow.js` e mapeia os estados/transições do conversation flow. Ajuda a entender como o cliente navega pelo menu e identificar onde adicionar novas etapas.

## Como usar

Quando o usuário pedir para entender ou modificar o fluxo de pedidos, use esta skill para:
1. Ler o arquivo `flow.js` 
2. Identificar os estados (ex: INICIO, ESCOLHER_LANCHE, CONFIRMAR_PEDIDO)
3. Mapear as transições entre estados
4. Identificar onde fazer modificações
