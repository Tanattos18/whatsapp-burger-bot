# Skill: Bot WhatsApp

Lê `bot.js` para entender a conexão com WhatsApp Web e processamento de mensagens.

## Como usar

Quando houver problemas com conexão WhatsApp ou mensagens, use esta skill para:
1. Ler `bot.js` para entender autenticação
2. Verificar eventos: qr, authenticated, ready, message
3. Entender обработamento de botões
4. Debugar erros de conexão
5. Re-autenticar se necessário
